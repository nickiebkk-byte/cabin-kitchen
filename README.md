# แต่งครัวปูน CABIN

หน้าเว็บให้ลูกค้าลองแต่งครัวเคาน์เตอร์ปูนด้วยบานและตู้แขวน CABIN 9 ซีรีส์
(CHIC, G6, JUNO, HENLEY, HOLLYN, PEARL PISTACHIO, CURVE GRAY, CURVE DIAMOND, LUCIDA DARK OAK)

- ครัวตัว I, ตัว L และตัว U จัดแต่ละผนังแยกกัน มีโซนมุมเข้าผนัง 60 ซม. บอกให้เห็น
- ผสมสินค้าได้หลายซีรีส์ในครัวเดียว รายการสินค้าบอกซีรีส์ของแต่ละชิ้น หรือเปลี่ยนทั้งครัวเป็นซีรีส์เดียวในคลิกเดียว
- วางตู้ บาน ซิงก์ เตา ช่องเครื่องดูดควัน ประตู และหน้าต่างได้อิสระบนผนัง
- กำหนดความยาวผนังและเคาน์เตอร์ของแต่ละผนัง เปลี่ยนสีผนัง ตัวเคาน์เตอร์ ท็อป และพื้น
- ดูแบบ 3D หมุนรอบห้องได้ ทุกผนังต่อกันเป็นมุมฉาก
- บันทึกแผนครัวเป็น PNG หรือ PDF (เลือกภาพ 2D, 3D หรือทั้งสองแบบ) พร้อมตารางรายการสินค้าและจำนวน

## ไฟล์ในโฟลเดอร์

```
index.html              หน้าเว็บทั้งหมด (โค้ด + ข้อมูลสินค้า)
manifest.webmanifest    ชื่อแอปและไอคอนสำหรับ "เพิ่มไปยังหน้าจอโฮม"
favicon.ico             ไอคอนแท็บเบราว์เซอร์
icons/                  ไอคอนหน้าจอโฮม iPhone/iPad (180) และ Android (192, 512, maskable)
img/                    ภาพสินค้าหน้าตรง (รหัส Article.webp) และภาพห้องตัวอย่างของแต่ละซีรีส์
.nojekyll               ให้ GitHub Pages เสิร์ฟไฟล์ตรงๆ ไม่ผ่าน Jekyll
```

## เอาขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `cabin-kitchen`) ตั้งเป็น Public
2. อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ขึ้นไปที่ราก (root) ของ repo ให้ `index.html` อยู่ชั้นบนสุด
   - ผ่านเว็บ: Add file → Upload files → ลากทั้งโฟลเดอร์มาวาง แล้ว Commit
   - ผ่านคำสั่ง:
     ```bash
     git init && git add . && git commit -m "แต่งครัวปูน CABIN"
     git branch -M main
     git remote add origin https://github.com/<ชื่อผู้ใช้>/cabin-kitchen.git
     git push -u origin main
     ```
3. ไปที่ Settings → Pages → Build and deployment → Source: **Deploy from a branch**
   เลือก Branch **main** โฟลเดอร์ **/ (root)** แล้วกด Save
4. รอ 1–2 นาที หน้าเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/cabin-kitchen/`

ไฟล์ `.nojekyll` ขึ้นต้นด้วยจุด เลยอาจถูกซ่อนในหน้าต่างไฟล์ ถ้าอัปผ่านเว็บแล้วไม่ติดไปด้วย ไม่เป็นไร หน้าเว็บยังทำงานได้

## ต้องเปิดผ่านเว็บ ไม่ใช่ดับเบิลคลิกไฟล์

ถ้าเปิด `index.html` จากเครื่องตรงๆ (file://) ปุ่มบันทึก PNG/PDF จะใช้ไม่ได้ เพราะเบราว์เซอร์บล็อกการอ่านภาพจากไฟล์ในเครื่อง
ทดสอบในเครื่องได้ด้วย `python3 -m http.server` ในโฟลเดอร์นี้ แล้วเปิด `http://localhost:8000`

## สิ่งที่โหลดจากอินเทอร์เน็ต

- ฟอนต์ Anuphan, IBM Plex Sans Thai, IBM Plex Mono จาก Google Fonts
- three.js r128 จาก cdnjs และ OrbitControls จาก jsDelivr (โหลดเมื่อกดดู 3D หรือส่งออกภาพ 3D)
- jsPDF 2.5.1 จาก cdnjs (โหลดเมื่อกดบันทึก PDF)

## แก้ข้อมูลสินค้า

ข้อมูลอยู่ในบรรทัด `const ITEMS=` และ `const SERIES=` ใน `index.html`
- `ITEMS` — รหัส Article → ชื่อ (`n`), ประเภท (`t`), กว้าง (`w`) และสูง (`h`) เป็นซม., ข้อความขนาด (`sz`), เป็นตู้แขวนหรือไม่ (`up`)
- `SERIES` — ชื่อซีรีส์ วัสดุ สีตัวอย่าง ภาพห้อง และรายการ Article ในซีรีส์

เพิ่มสินค้าใหม่: ใส่ภาพหน้าตรงพื้นหลังโปร่งใสเป็น `img/<Article>.webp` แล้วเพิ่มรายการใน `ITEMS` และใน `arts` ของซีรีส์นั้น

## หมายเหตุ

- ขนาดและรหัสสินค้าตามป้ายหน้าร้าน ภาพเป็นการจำลองเพื่อดูไอเดีย
- ครัวที่ลูกค้าจัดไว้ถูกจำในเบราว์เซอร์ของลูกค้าเอง (localStorage) ไม่ได้ส่งไปที่ไหน

## เพิ่มไปยังหน้าจอโฮม

- iPhone/iPad (Safari): ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" ไอคอนชื่อ "ครัวปูน 3D"
- Android (Chrome): เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
- เปิดจากไอคอนแล้วจะเต็มจอแบบแอป ไม่มีแถบที่อยู่เว็บ

เปลี่ยนไอคอน: แทนไฟล์ใน `icons/` และ `favicon.ico` ขนาดเท่าเดิม ชื่อเดิม
